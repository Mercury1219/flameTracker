# Flame Tracker v1.5.0

Flame Tracker now provides live English and Simplified Chinese interface switching while preserving the analysis behavior of v1.4.2.

## What's new vs v1.4.2

### Added

- Language menu with English and Simplified Chinese options.
- Immediate translation of the current Preview and Tracking panels.
- Persistent language preference across application launches.
- Centralized translations for menus, controls, dialogs, messages, and graph axes.
- Chinese README and localization regression tests.

### Changed

- Display translations are separated from canonical tracking values, so language switching does not affect calculations or exported data semantics.

## Install

Download `flameTracker-v1.5.0-windows-x64.exe` from this release, or run from source:

```bash
python -m pip install -r requirements.txt
cd scripts
python flameTracker.py
```
