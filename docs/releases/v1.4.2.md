# Flame Tracker v1.4.2

This release makes Scale measurement visible, guided, and reliable by moving
endpoint selection and known-length entry into one Qt dialog.

## What's new vs v1.4.1

### Fixed

- Replaced the hidden, blocking OpenCV scale workflow with one visible dialog.
- Added an explicit warning when Scale is selected before media is opened.
- Preserved original-frame pixel accuracy when the image is scaled for display.
- Fixed the empty analysis-template function so all Python sources compile.

### Changed

- Added `VERSION` as the single release-version source.
- Added regression tests and a six-job CI matrix for Windows, Linux, and macOS
  on Python 3.11 and 3.13.
- Added dependency files, contributor guidance, a changelog, README badges, and
  a reproducible PyInstaller specification.

### Added

- Windows x64 single-file executable.
- SHA-256 checksum file for the executable.

### Removed

- Nothing.

## Install

Windows users can download `flameTracker-v1.4.2-windows-x64.exe` from this
release and run it directly. Source users can install dependencies and launch
the application with:

```bash
python -m pip install -r requirements.txt
cd scripts
python flameTracker.py
```

## Verification

- `python -m compileall -q scripts tests`
- `QT_QPA_PLATFORM=offscreen python -m pytest -q` (`4 passed`)
